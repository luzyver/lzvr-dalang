# Contributing to Dalang

Thanks for helping. This file covers how to get a working copy, the checks a change must pass and how commits and
pull requests are written. How Dalang itself works is in the [guide](docs/guide.md).

## Setup

Requirements: Node.js 22.13 or newer (`.nvmrc`), git, and for the parts you touch the `codex`, `claude`, `gh` or
`glab` CLIs. Tests use fakes for all of them (`test/fake-*.mjs`), so none is needed to run the suite.

```sh
npm ci
cp .env.example .env          # set LZVR_TOKEN (openssl rand -hex 32) and AUTH_BYPASS=true for local work
npm run dev                   # tsx src/main.ts, http://127.0.0.1:9876
```

On Windows, `run.cmd -Dev` does the same in one go (see [Develop](docs/guide.md#develop)).

## Layout

| Path | What it is |
| --- | --- |
| `src/` | The gateway: Fastify server, agent runners, git, MCP, databases, SSH (TypeScript, ESM) |
| `public/` | The panel: Preact + htm, no build step; `public/vendor` is generated by `npm run vendor` |
| `test/` | Vitest suites (`*.test.ts`) and fake CLIs |
| `scripts/` | Run/autostart scripts, the vendoring script, agent git hooks |
| `skills/` | Dalang's own skills, given to chat agents |

## Checks

Every change must pass, and CI runs the same on Linux and Windows:

```sh
npm run typecheck
npm test
npm run build
```

Add or update a test for behaviour you change. Keep tests free of network access and real accounts; extend a fake
instead.

After updating a browser library (Preact, CodeMirror, xterm.js, highlight.js, ...), run `npm run vendor` and commit
`public/vendor` with it. Never edit files in `public/vendor` by hand.

## Style

- TypeScript `strict` with `noUncheckedIndexedAccess`; no `any` where a type can be named.
- Match the surrounding code: naming, comment density and idiom. Comments say *why*, not *what*.
- `.editorconfig` sets UTF-8, LF and two-space indentation.
- User-facing behaviour, configuration and API changes go into [docs/guide.md](docs/guide.md) in the same change.

## Commits and pull requests

Commit subjects follow [Conventional Commits](https://www.conventionalcommits.org/) with a capitalised, imperative
description:

```
feat: Add SSH hosts for agents and encrypt stored secrets
fix: Stop close listeners piling up on the response while replaying history
refactor: ...
```

Types in use: `feat`, `fix`, `refactor`, `style`, `build`, `test`, `docs`, `chore`.

Open pull requests against `master`, fill in the template, and keep one topic per pull request. Notable changes get a
line under "Unreleased" in [CHANGELOG.md](CHANGELOG.md).

## Security

Do not open public issues for vulnerabilities; see [SECURITY.md](SECURITY.md).
